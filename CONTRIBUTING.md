# Contributing

## Workflow

1. Open an Issue for the task, question, bug, or idea.
2. Work on a branch.
3. Submit a Pull Request and request review.
4. Merge only after review. Routine changes may be pushed directly to `main` by Muse with team approval (SD-006); significant changes go through a Pull Request and merge only after review.

## Rules

- No fabrication: every citation verifiable, every result traceable to an experiment record.
- Label facts, hypotheses, and recommendations distinctly.
- Report negative and inconclusive results honestly.
- Research-direction changes, final conclusions, and public claims need human approval.
- Never commit API keys or secrets. Use environment variables or GitHub Secrets.
- Tasks rotate; every task has an owner responsible for its result.

## Task board

Loop & Orbit Research Board: Backlog → Literature Review → Research Design → AI Execution → Human Review → Completed.
