# Literature

## Files

- `bibliography.bib` — full citation data for the reading list.
- `literature-matrix.csv` — one row per paper. Only include papers that have been **personally verified** (the source can be opened). Columns: Paper, Year, Link, Relevant direction, What it did, Method, Main finding, Still unsolved / our opening, Reader, Verified.
- `reading-notes/` — reading notes, named `year-firstauthor-keywords.md`.
- `related-work/` — notes on neighbouring fields.
