# AI Agent Charter (working draft)

## Roles

- **ChatGPT** — research planning, critical review, experiment-design suggestions.
- **Claude** — literature surveys, code review, experiment-design critique.
- **Codex** — code implementation, experiment frameworks, data processing.
- Other AI tools as needed; their use must be recorded.

## Permissions

| Permission | AI agents |
|---|---|
| Read the repository | Allowed |
| Create drafts | Allowed |
| Modify their own branches | Allowed |
| Create Issues | Allowed |
| Create Pull Requests | Allowed |
| Auto-merge Pull Requests | Forbidden |
| Change core research hypotheses | Requires human approval |
| Delete raw experiment data | Forbidden |
| Publish WeChat articles | Forbidden |
| Sign agreements on behalf of the group | Forbidden |

## Rules

- All AI-generated content must be reviewed by a human.
- AI use must be recorded (see the AI work log template below).
- AI is a tool, not a decision-maker. Research judgement cannot be outsourced.

## AI work log template

Task ID / Project / Agent / Model and version / Date / Input / Prompt or instructions / Output / Files modified / Tests run / Results summary / Review status / Human reviewer / Review date / Review notes / Next steps / Related Issues / Related PRs / Notes
