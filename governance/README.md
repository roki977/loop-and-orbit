# Governance (working draft)

> Working draft. The full Governance Charter v1.0 (2026-11-17) needs unanimous approval to take effect. These files are the working English version; the full Charter text is in the planning conversation.

## Confirmed decisions

- Organization type: independent.
- GitHub openness: mixed — public by default, private by necessity (knowledge base public; unpublished research and sensitive experiments private for now).
- WeChat publishing: selective — quality over quantity.

## Decision authority

| Matter | How it is decided |
|---|---|
| Research direction and core hypotheses | Unanimous |
| Experiment design and technical plans | 2/3 majority |
| Creating or deleting GitHub repositories | Unanimous |
| WeChat publication | Unanimous |
| Paper submission | Unanimous |
| Membership changes | Unanimous |
| Governance Charter amendments | Unanimous |
| Day-to-day task assignment | Rotating lead decides |
| API budget | 2/3 majority |
| External collaboration | Unanimous |

The AI research commander handles research planning, literature surveys, critical review, and experiment-design suggestions. It holds no legal identity, no voting rights, and no asset ownership. Final research decisions are made by humans.

## Files

- `research-principles.md` — the principles all work follows.
- `ai-agent-charter.md` — what AI agents may and may not do.
- `contribution-guide.md` — workflow, branch protection, and the task board.
- `decision-log.md` — record of decisions, with date, context, and status.
